> 机器可读数据：`data/pieces.json`（30 种棋子定义）、`data/combat-matrix.json`（30×30 胜负矩阵 + 假设清单）。

## 2. 战斗结果六类

| 键 | 含义 |
|---|---|
| attacker_wins | 攻方胜（守方被消灭） |
| defender_wins | 守方胜（攻方被消灭） |
| both_destroyed | 双方消灭 |
| no_result | 不分胜负（双方存活） |
| scout | 侦察（揭示守方身份，不消灭） |
| forbidden | 不允许交战（域不匹配/不可动棋子不攻击） |

## 4. 战斗判定的关键非对称性（已在矩阵中落实）

1. **工兵 vs 炸弹/炮垒 = 攻者胜**：工兵攻→工兵胜；炸弹/炮垒攻→工兵败。
2. **战斗机 vs 飞弹**：战斗机攻→战斗机胜；飞弹攻→双方消灭。
3. **战斗机 vs 战斗机 = 攻者胜**。
4. **炮舰 vs 炮垒 = 攻者胜**（炮舰攻炮垒胜；炮垒攻炮舰胜）。
5. **炮垒 vs 机关枪**：炮垒攻→炮垒胜；机关枪攻→双方消灭（争议 C4）。
6. **飞弹 vs 潜艇**：潜艇存活、飞弹移除（记「守方胜」并备注）。

## 5. 侦察与暗棋

- 棋子身份对敌方**隐藏**（军棋传统暗棋）。
- 交战双方揭示；**侦察机**对目标执行「侦察」——只揭示身份、不消灭（对地雷「不分胜负」）。
- 侦察/交战日志与揭示状态是「暗棋信息不泄漏」验收项的基础（第二阶段）。
