陆海空三军棋 · Windows 免安装版
==============================

怎么打开
--------
1. 先把整个 triservice-chess-win-x64 文件夹解压出来。
   不要只把 TriserviceChess.exe 单独拖出来，旁边的 .dll 和
   resources 文件夹是程序必需的。
2. 双击 TriserviceChess.exe，等一两秒会弹出一个独立窗口，
   窗口标题是「陆海空三军棋」，里面就是棋盘。
3. 文件夹里还放了一份 TriserviceChess-web.html：
   万一 exe 被安全软件或公司电脑策略拦下，直接双击这个 html，
   用 Edge / Chrome 打开同样能玩，功能和存档完全一样。

为什么文件名是英文
------------------
压缩包里的文件和文件夹都用英文名，是为了在任何语言的 Windows、
任何解压工具里都不会被改成乱码或问号。程序窗口、界面、规则说明
里面全部是中文。

不需要安装，不需要联网，不需要 Node.js 或任何运行库。

第一次运行可能出现的情况
------------------------
* Windows SmartScreen 提示「已保护你的电脑」：
  这是自己打包、没有购买代码签名证书的程序，属于正常提示。
  点「更多信息」→「仍要运行」即可。
* 杀毒软件误报：可以只用 TriserviceChess-web.html 玩。
* 双击后没反应：确认整个文件夹都解压完了（有些工具只解压出 exe）。

怎么玩
------
开局界面选「双人对战」或「人机对战」，按提示摆棋，然后开始。
双方棋子都是暗棋，碰撞后按传统三军棋的吃子规则判定。
棋盘、规则说明、战报回放都在程序里，按界面上的按钮即可。

数据和存档
----------
存档与回放存在程序自己的本地存储里，不上传任何地方、不联网。
想换电脑继续，用界面里的「导出存档 / 导入存档」。

版本
----
游戏内核 1.0，棋盘采用国防医学院（NMTH）历史棋盘整理版，
陆军 30 / 海军 20 / 空军 10，共 60 枚棋子。
